- **"Learn from chat" works with thinking models.** A local model that reasons before it answers (such as Qwen behind litellm or Ollama) used up its whole answer on thinking, and Sennit then said there was nothing new to remember. It now gets enough room to finish. When something does go wrong, the message tells you what happened: the model took too long, was cut off, answered with an error, or did not answer with a list. If learning is off for this chat, the message has a button that opens the setting.
