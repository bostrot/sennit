一个收件箱。你的服务器。中间没有任何人。

Sennit 把你所有的聊天汇集到一个私密收件箱。它是专为桥接打造的 Matrix 客户端：连接你自己运行的家庭服务器和你选择的桥接，来自 WhatsApp、Signal、Telegram、Google Messages、Mattermost、短信和 Matrix 等网络的对话就会出现在同一个列表里。没有中间商，不需要 Sennit 账号，任何消息都不会经过我们的服务器——我们根本没有服务器。

一个人，一个对话
同一个人在三个网络上的聊天会合并成一个对话。回复会通过对方最后一条消息所在的网络发出，也可以由你指定。只有完全匹配时才会自动合并，其余情况都只是建议，由你决定。

从设计上保护隐私
• 通过 Matrix 端到端加密，支持设备验证、交叉签名和密钥备份
• 自动删除消息，可按对话设置
• 已读回执、输入状态和在线状态，各有独立开关
• 无追踪、无广告；匿名使用统计仅在你同意后发送
• 基于 AGPL-3.0 开源：每一行代码都公开

自带 AI（SENNIT PRO）
• 回复建议和快捷消息来自你自己托管的语言模型：任何提供 OpenAI 兼容 API 的服务器均可，例如 Ollama 或 llama.cpp
• 语音转写和语义搜索在设备上运行，音频和消息留在你的硬件上，也可以使用你自己运行的服务
• 内置 MCP 服务器，让你自己的智能体可以搜索和发送消息，权限由受限的 API 密钥控制
• Home Assistant、paperless-ngx 和共享日历集成

日常聊天，免费
• 通话、语音消息、照片和视频、投票、位置共享
• 定时发送和提醒
• 在聊天中直接接受、拒绝或改期日历邀请
• Android 上无需 Google 服务即可收到通知，通过你自己的同步连接或 UnifiedPush
• 主屏幕小组件、手表应用和双栏平板布局
• 加密备份

你的服务器，你的桥接
Sennit 是应用本身；你需要自备 Matrix 家庭服务器以及所用网络的桥接（mautrix 桥接是参考配置）。Sennit 会自动发现你的桥接，并引导你逐一连接各个网络，包括扫码登录。运行家庭服务器需要一定的技术基础，而这份独立正是它的意义所在。

聊天免费。Sennit Pro 是一次性应用内购买，不是订阅，可解锁 AI 功能、语义搜索、语音转写、MCP 服务器和各项集成。

Sennit 与通过桥接访问的网络没有任何关联。桥接是在自动操作你自己的账号；各网络的条款是否允许这样做，由你与该网络之间决定。
