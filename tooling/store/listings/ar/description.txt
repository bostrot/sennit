صندوق وارد واحد. خادمك أنت. لا أحد في المنتصف.

يجمع Sennit كل محادثاتك في صندوق وارد خاص واحد. إنه تطبيق Matrix مصمَّم للجسور: اربطه بخادم منزلي تديره بنفسك وبالجسور التي تختارها، فتصل المحادثات من شبكات مثل WhatsApp وSignal وTelegram وGoogle Messages وMattermost والرسائل النصية SMS وMatrix إلى قائمة واحدة. لا وسيط، ولا حساب لدى Sennit، ولا تمر أي رسالة عبر خوادمنا. فنحن لا نملك أيًّا منها.

شخص واحد، محادثة واحدة
يصبح الشخص نفسه على ثلاث شبكات محادثة واحدة. تُرسل الردود عبر الشبكة التي وصلت منها رسالته الأخيرة، أو عبر الشبكة التي تختارها. لا يتم الدمج تلقائيًا إلا عند التطابق التام؛ وكل ما عدا ذلك اقتراح يعود القرار فيه إليك.

الخصوصية من الأساس
• تشفير تام بين الطرفين عبر Matrix، مع التحقق من الأجهزة والتوقيع المتبادل والنسخ الاحتياطي للمفاتيح
• رسائل مختفية، يمكن ضبطها لكل محادثة
• إشعارات القراءة ومؤشر الكتابة وحالة الاتصال، لكل منها مفتاح مستقل
• لا تحليلات، ولا تتبّع، ولا إعلانات
• مفتوح المصدر بترخيص AGPL-3.0: كل سطر متاح للجميع

ذكاؤك الاصطناعي الخاص (SENNIT PRO)
• اقتراحات الردود والرسائل السريعة من نموذج لغوي تستضيفه بنفسك: أي خادم يوفّر واجهة API متوافقة مع OpenAI، مثل Ollama أو llama.cpp
• تفريغ الصوت والبحث الدلالي على الجهاز نفسه، فيبقى الصوت والرسائل على أجهزتك، أو على خوادم تديرها أنت
• خادم MCP مدمج يتيح لوكلائك الخاصين البحث والإرسال، ضمن صلاحيات محددة بمفاتيح API
• تكامل مع Home Assistant وpaperless-ngx والتقويمات المشتركة

المراسلة اليومية، مجانًا
• مكالمات، ورسائل صوتية، وصور وفيديوهات، واستطلاعات، ومشاركة الموقع
• الإرسال المجدول والتذكيرات
• دعوات التقويم: اقبلها أو ارفضها أو اقترح موعدًا جديدًا داخل المحادثة نفسها
• على Android: إشعارات دون خدمات Google، عبر اتصال المزامنة الخاص بك أو UnifiedPush
• أدوات للشاشة الرئيسية، وتطبيق للساعة، وتخطيط بعمودين للأجهزة اللوحية
• نسخ احتياطية مشفّرة

خادمك، وجسورك
Sennit هو التطبيق؛ أما الخادم المنزلي لـ Matrix والجسور للشبكات التي تستخدمها فتجلبها أنت (جسور mautrix هي الإعداد المرجعي). يكتشف Sennit جسورك ويرشدك خطوة بخطوة لربط كل شبكة، بما في ذلك تسجيل الدخول برمز QR. تشغيل خادم منزلي يتطلب بعض الخبرة التقنية، وهذه الاستقلالية هي الغاية كلها.

المراسلة مجانية. Sennit Pro عملية شراء واحدة داخل التطبيق، وليس اشتراكًا، وتفتح ميزات الذكاء الاصطناعي والبحث الدلالي وتفريغ الصوت وخادم MCP والتكاملات.

لا يرتبط Sennit بالشبكات التي يمكن الوصول إليها عبر الجسور. فالجسر يؤتمت حساباتك أنت؛ أما ما إذا كانت شروط الشبكة تسمح بذلك فأمر بينك وبين تلك الشبكة.
